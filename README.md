# Dusty Drawer

> 把攒了一窗口的标签页丢进「抽屉」，在新标签页里盯着它们，处理完就清空。

**Dusty Drawer = 临时书签 + 新标签页看板 + 一键打开并清理**

它是一个 Chrome 扩展，专治「标签页攒了一窗口却不敢关」。

---

## 它解决什么问题？

查资料、写文档、做调研时，窗口里的标签页越开越多。`Ctrl + Shift + D` 能把它们一键存成书签，但存完就结束了——书签发霉，任务也被抛到九霄云外。

Dusty Drawer 把「待处理的书签」直接放在你每天要看无数次的新标签页上，让你没法假装没看见。

---

## 工作流

它的循环只有三步：

1. **丢进去**：一键把当前窗口的所有标签页存成书签文件夹。
2. **看得见**：每次打开新标签页，「抽屉」里的待处理文件夹就在眼前。
3. **拿出来**：点一下，整组链接在新窗口打开，原文件夹自动删除。

形成一个最小闭环：保存 → 提醒 → 打开 → 清理。

---

## 核心功能

### 保存窗口标签页

| 入口 | 用法 |
|------|------|
| 右键菜单 | 在任意页面右键 → 保存当前窗口标签页到「抽屉」，文件夹名默认为当前时间 |
| 扩展图标 | 点击工具栏图标，输入自定义文件夹名，然后「保存并关闭窗口」 |

保存后会自动关闭原窗口。

### 自定义新标签页

安装后，Chrome 的新标签页会由 Dusty Drawer 控制：

- **当前窗口/标签页**：按窗口分组列出，点击直接跳转到对应标签。
- **工作区书签**：以卡片形式展示待处理的书签文件夹。
- **模拟书签栏**：保留 Chrome 默认新标签页顶部的书签栏体验，可在设置中关闭。

当浏览器标签页发生增删、切换、移动时，新标签页会自动刷新。

### 一键打开并清理

点击任意工作区书签文件夹，扩展会：

1. 在新窗口打开文件夹里的所有链接；
2. 从工作区删除这个文件夹。

你也可以在设置中选择「以标签组形式打开」，让新窗口更整洁。

## 开始使用

本扩展不依赖任何前端框架。

### 安装

在 [Chrome 应用商店](https://chromewebstore.google.com/detail/dusty-drawer/ckjhlfdcakdniccnkpfcclinehggbhcg) 中安装。

或者本地以开发者模式加载。

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本项目中的 `src` 文件夹。

### 首次配置

首次安装时，扩展不会自动创建工作区，而是会自动打开设置页面，提醒你：

> 尚未设置工作区文件夹

你需要在设置里「新建工作区」或「选择文件夹」。这一步完成后，扩展才能保存标签页。

如果还没设置工作区：

- 新标签页会提示设置；
- Popup 会显示「未设置工作区」并引导到设置；
- 右键菜单会变成「⚠ [请先设置抽屉文件夹]」。

---

## 设置项

| 设置 | 说明 |
|------|------|
| 新建工作区 | 创建一个新的书签文件夹作为工作区 |
| 当前工作区文件夹 | 选择已有的书签文件夹作为工作区 |
| 关闭顶栏书签栏 | 隐藏新标签页顶部的模拟书签栏 |
| 标题自动换行 | 长标题换行显示，否则显示省略号 |
| 以标签组形式打开 | 打开工作区书签时自动归为一个标签组 |
| 关闭打开单个链接时的页面动画效果 | 跳转时不播放闭幕动画 |
| 清空工作区 | 弹出提示，引导你到 Chrome 书签管理器手动清理（扩展不会直接删除） |

---

## 注意事项

- 工作区文件夹不会自动创建，这是刻意的：它让你明确知道数据存在哪里。
- 打开工作区书签会删除原文件夹，所以处理前请确认里面的内容。

## 项目结构

```
├── background.js      # Service Worker，协调所有操作
├── constants.js       # 共享常量
├── icons/             # 扩展图标
│   ├── icon16.png
│   ├── icon32.png
│   ├── icon48.png
│   ├── icon64.png
│   └── icon128.png
├── popup/             # 工具栏图标弹窗
├── newtab/            # 自定义新标签页
└── options/           # 设置页面
```
